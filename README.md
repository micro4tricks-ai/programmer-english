# إنجليزي المبرمج

صفحة واحدة لتعلم الإنجليزي اللي المبرمج بيحتاجه، ومعاها تقييمات للأطفال حسب السن.

## فيها إيه
- **الأسبوع المكثّف**: 7 أيام، كل يوم فيه شرح وتمارين وتحدي واختبار.
- **تقييمات حسب السن (6–12 سنة)**: اختبار لكل سن فيه 12 سؤال (صور وأصوات وقراءة وأساسيات برمجة)، مربوط بمستويات Cambridge Starters وMovers وFlyers وإطار CEFR، ومعاه تقرير للأهل.
- **المكتبة**: حوالي 200 مصدر، مع فلاتر للسن والتصنيف (مجاني، عربي، مفضّل) وبحث واقتراح عشوائي.
- نصوص محلولة، وبنك مفردات ببطاقات ونطق، وجمل جاهزة، وقواعد، وخطة 12 أسبوع، ورسائل أخطاء Python، ومراجع.
- التقدم بيتحفظ في المتصفح، وينفع تنقله لجهاز تاني بـ«كود التقدم».

## النشر على GitHub Pages
1. اعمل Repository جديد وارفع فيه `index.html` و`.nojekyll` (و`README.md` لو حابب).
2. من **Settings ← Pages** اختار **Deploy from a branch**، والـ branch `main` والفولدر `/ (root)`.
3. بعد دقيقة هيبقى الموقع على `https://<username>.github.io/<repo>/`.

الصفحة ملف واحد ومش محتاجة build ولا سيرفر. الخطوط بتتحمّل من Google Fonts.

> `app.html` نسخة الصفحة من غير `<head>` (للنشر كـ Artifact). للموقع استخدم `index.html`.
