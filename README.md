## نبذة

صفحة واحدة لتعلّم الإنجليزية التي يحتاجها المبرمج في عمله كل يوم: قراءة رسائل الأخطاء والتوثيق، وكتابة الـ commits والـ README وتقارير الأخطاء، والتواصل مع الفريق والعملاء، والنطق الصحيح للمصطلحات، والاستعداد للمقابلات.

تبدأ بـ **أسبوع مكثّف** (7 أيام، نحو ساعتين يومياً)، ثم تكمل **خطة 12 أسبوعاً** (نحو 40 دقيقة يومياً) لتثبيت ما تعلّمته والوصول إلى الطلاقة في العمل. الشرح بالعربية والأمثلة من نصوص حقيقية يقابلها المبرمج فعلاً.

## الأسبوع المكثّف

| اليوم | الموضوع |
|:-:|---|
| 1 | اقرأ رسائل الأخطاء والـ Traceback |
| 2 | اقرأ التوثيق (Documentation) |
| 3 | لغة الكود: الأسماء والتعليقات والـ Docstrings |
| 4 | اكتب: Commits وREADME وتقارير الأخطاء |
| 5 | التواصل: تسأل وتطلب وترد على عميل |
| 6 | اسمع وانطق: المصطلحات والرموز |
| 7 | اعرض شغلك: المقابلات والبورتفوليو |

كل يوم بالترتيب نفسه: **افهم** القاعدة بأمثلة، ثم **تمرّن** على كود أو نص حقيقي، ثم **انسخ** الجمل الجاهزة، و**احفظ** كلمات اليوم وانطقها، و**اقرأ** من المكتبة، وفي الآخر **تحدٍّ** و**اختبار**. لا تنتقل لليوم التالي قبل أن تجيب إجابة صحيحة عن 4 من 5 أسئلة.

## الأقسام بالتفصيل

- **اختبارات:** أسئلة كل يوم، و«مراجعة شاملة» على الاختصارات وأكواد HTTP وGit والقواعد، وتبويب للأسئلة التي أخطأت فيها.
- **نصوص محلولة (20):** Traceback من سكربت فواتير، وصفحة توثيق دالة، وREADME لمشروع أتمتة، وBug report على GitHub، وإيميل عميل، ورسائل Slack، وسؤال في منتدى n8n، وإعلان وظيفة، وخطأ JavaScript في الكونسول، وMerge conflict، وحدود الطلبات في توثيق API، وتعليقات Code review، ووصف Pull request، وRelease notes، وإجابة Stack Overflow، وإيميل أمان، وتقرير Post-mortem، وحوارات: Standup ومقابلة عمل ومكالمة عميل.
- **بنك المفردات:** بطاقات بالنطق الصوتي، ومنها اختصارات العمل (LGTM وASAP وWIP…)، والـ Phrasal verbs، والذكاء الاصطناعي، وDevOps، والأمان، وJavaScript، وn8n، والاجتماعات.
- **جمل جاهزة:** شرح الكود، وطلب المساعدة، والدعم، والإيميلات، والاجتماعات، والمقابلات، وCode review، ووصف PR، والتقدير والمواعيد، والعروض، والرسائل السريعة، والتفاوض مع العميل.
- **رسائل الأخطاء:** Python وJavaScript وGit والطرفية وأكواد HTTP، ولكل رسالة معناها وسببها وحلها.
- **المكتبة:** بحث وفلاتر (مجاني، عربي، مفضّل)، واقتراح عشوائي، ولكل مصدر ماذا تقرأ ومتى.
- **كلمة الأسبوع** في أعلى الصفحة، بمثال ونطق.

## المزايا

- 🔊 **نطق صوتي** لكل كلمة ومثال من المتصفح نفسه.
- 📈 **متابعة التقدّم:** أيام متتالية، ونسبة الإجابات الصحيحة، والكلمات المحفوظة، وتقدّم الخطة.
- 🔁 **«كود التقدّم»** لنقل تقدّمك إلى جهاز آخر دون حساب.
- 🪶 **ملف واحد** (`index.html`) بدون مكتبات ولا خطوة بناء، ويفتح على أي جهاز.
- 🔒 **بدون تسجيل ولا تتبّع.**

## طريقة بناء الصفحة

الصفحة كلها في `index.html`: التنسيق في `<style>`، والمحتوى والمنطق في `<script>`. المحتوى مصفوفات بيانات داخل السكربت، فإضافة محتوى جديد تعني إضافة عنصر للمصفوفة المناسبة:

| المصفوفة | المحتوى |
|---|---|
| `SPRINT` | أيام الأسبوع المكثّف (الشرح، التمرين، الكود، التحدي، الاختبار) |
| `WEEKS` | أسابيع الخطة الكاملة |
| `VOCAB` | بنك المفردات |
| `READINGS` | النصوص المحلولة وأسئلتها |
| `PHRASES` | الجمل الجاهزة |
| `GRAMMAR` | قواعد المبرمج |
| `ERRORS` | رسائل الأخطاء |
| `EXTRA_QUIZ` | أسئلة المراجعة الشاملة |
| `LIBRARY` | مصادر المكتبة |
| `REFS` | المراجع التي بُني عليها المحتوى |

التقدّم محفوظ في `localStorage` تحت المفتاح `eng_plan_v1`.

**النشر:** GitHub Pages من الفرع `main` والمجلد `/ (root)`. أي تعديل يُرفع على `main` يظهر على الموقع خلال دقيقة تقريباً. ولأنها ملف واحد، يمكن رفعها كما هي على أي استضافة.

## English summary

**Programmer English** is a single-page site that teaches Arabic-speaking developers the English they use at work every day. Explanations are in Arabic; every example is real developer text.

- **7-day intensive week** (~2 h/day): reading errors and tracebacks, reading docs, naming and comments, writing commits/READMEs/bug reports, communicating with teams and clients, pronunciation, and interviews. Each day ends with a 5-question quiz.
- **12-week plan** (~40 min/day) with reading, listening, writing, speaking and a small project every week.
- **436 vocabulary words** with audio, **20 worked texts**, **73 ready-made sentences**, **49 explained error messages**, **24 grammar rules**, **57 quiz questions** and a **149-resource library** with search and filters.
- Progress is saved in the browser and can be moved to another device with a progress code. No sign-up, no tracking.
- One `index.html` file, no framework and no build step, published on GitHub Pages. Released under the [MIT License](LICENSE).
